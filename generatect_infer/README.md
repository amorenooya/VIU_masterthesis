# GenerateCT Finetuned Inference & Visualization

This repository contains scripts to run inference with a finetuned [GenerateCT](https://github.com/) model and visualize results.

## Structure

generatect_finetune/

├── inference.py # Run model inference on prompts

├── super_resolution.py # Run super-resolution model inference on prompts and low-resolution images

├── visualization.py # Pairing and plotting utilities generated images

├── utils.py # Shared helpers

├── requirements.txt

└── README.md
